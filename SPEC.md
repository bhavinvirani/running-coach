# Running Coach: spec

One page max. Phase 1 fills Decisions and Open risks; phase 3 finishes the rest.

## Decisions

- License: MIT. Permissive and standard for a public side project.
- Domain: the hosting provider's subdomain, no custom domain. Zero cost while there is one user; revisit if a domain is bought.
- Free hosting may require a card on file as long as $0 is charged. Research must confirm spend caps or alerts per provider.
- First-time setup imports the user's full Garmin history, so PBs cover every run. The import runs as a resumable background job; research must size the call volume against Garmin rate limits.
